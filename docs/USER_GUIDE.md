**磁盘上不存任何站点密码，无数据库可脱。只要记住唯一的主口令，在任何电脑、手机上，随时随地都能精确算出一模一样的强密码。**

## 一、各端下载与初次安装指南

所有官方预编译产物均可在 GitHub 仓库的 **[Releases](https://github.com/lylyuanliang/mantra-key/releases)** 页面获取。

### 1. Chrome / Edge 浏览器扩展（极力推荐）

密诀 Chrome MV3 扩展支持在任意 Chromium 内核浏览器（Google Chrome、Microsoft Edge、Brave、360极速浏览器、搜狗浏览器等）中运行，并内置了**在线静默一键热更新**服务。

#### 步骤 1：下载并解压到固定工具目录
1. 从 Releases 下载扩展压缩包：`mantra-key-chrome-extension-v0.1.0.zip`；
2. 将其解压到一个您日常存放常用工具的**固定目录**（例如：`D:\Tools\MantraKey` 或 `C:\Tools\MantraKey`）；
> ⚠️ **注意**：请不要解压在“系统临时目录”或随时会被清理的“下载文件夹”中，因为后续自动更新时，Native 代理会在该目录下原地直接热覆盖。

#### 步骤 2：在浏览器中加载扩展程序
1. 打开 Chrome 浏览器，在地址栏输入 `chrome://extensions` 并按回车（Edge 浏览器输入 `edge://extensions`）；
2. 打开页面右上角的 **「开发者模式」** 开关；
3. 点击左上角的 **「加载已解压的扩展程序」**；
4. 选择刚刚第一步解压的文件夹（如 `D:\Tools\MantraKey`）；
5. 此时，浏览器右上角扩展栏中就会出现“密诀 MantraKey”的小钥匙图标。

#### 步骤 3：激活在线静默自动更新服务（仅需运行一次）
1. 打开解压文件夹 `D:\Tools\MantraKey`；
2. 双击运行里面的 **`启用自动更新.bat`**；
3. 脚本会自动完成以下操作：
   - 自动扫描本地 Chrome / Edge，智能识别浏览器刚为 MantraKey 分配的专属 Extension ID 并加入通信白名单；
   - 将配套的轻量原生代理 `mantra-native-proxy.exe` 写入当前用户注册表（`HKCU`，**不需要管理员提权**，绿色无污染）；
4. 窗口显示 `[成功] MantraKey 原生自动更新服务已成功注册！` 后按任意键退出即可。

#### 以后如何升级？
以后当 GitHub 发布新版本时，点击扩展图标打开面板，顶栏会自动提示：
```text
🚀 发现新版本 v0.2.0 (当前: v0.1.0)   [⚡ 一键更新]
```
直接点击 **「⚡ 一键更新」**，本地代理会自动下载官方/加速包并原地解压覆盖，浏览器扩展在 1~2 秒内自动完成热重载并提示更新成功！

### 2. Android 移动端（双引擎穿透）

#### 步骤 1：安装 APK
从 Releases 下载 `mantra-key-v0.1.0-release.apk`，在手机上允许安装未知应用并完成安装。

#### 步骤 2：开启系统级自动填充 (AutofillService)
1. 打开密诀 App，进入「设置」；
2. 点击「开启系统自动填充服务」，系统将引导您跳转至 Android 系统设置；
3. 在“自动填充服务”列表中选择 **密诀 MantraKey**；
4. 开启后，在绝大多数手机浏览器或常规 App 中点击账号/密码框时，键盘上方将自动弹出密诀快捷悬浮气泡，点击即可一键计算并填充。

#### 步骤 3：开启自研辅助穿透输入法 (PenetrationIME)
针对**手机银行、证券、政务、数字人民币**等金融类 App（它们通常强制弹出自绘防录屏软键盘、禁用系统 Autofill 并拦截剪贴板）：
1. 在密诀 App 设置中开启「穿透输入法」；
2. 遇到此类金融 App 登录时，切换输入法为“密诀穿透键盘”；
3. 在键盘顶栏直接输入主口令，派生引擎将通过系统底层按键事件直接向密码框注入安全按键，**100% 击穿任何第三方 App 的防填充限制**。

### 3. Windows 桌面中枢与 HUD 快捷面板

1. 从 Releases 下载 `mantra-key-desktop-v0.1.0-windows-x64.zip`；
2. 解压至固定文件夹，双击运行里面的 `install_host.bat` 建立本地原生中继通道；
3. 运行 `mantra-desktop.exe`，按下全局快捷键即可在任何界面秒级唤起 HUD 暗黑悬浮卡片。

## 二、核心日常操作指南

### 1. 记忆主口令与「金丝雀防敲错指纹」

在传统密码管理中，用户总是担心：“如果我敲错了一个字母，密码会不会全乱了？”
密诀独创了 **金丝雀防手抖校验指纹 (Canary Fingerprint)**：
- 只要输入主口令，右侧就会实时根据不可逆哈希生成一个 **8 位专属十六进制指纹**（例如：`A6FAA80B`）；
- 这个指纹对每一个主口令是**恒定唯一**的。您只需记住自己指纹的前几位（或者看着顺眼）；
- 每次输入完主口令，眼角余光扫一眼指纹——只要指纹一致，即可 **100% 确信主口令没有敲错哪怕任何一个字符或空格**！
- 驻留安全内存 15 分钟后或手动点击「锁定」，主口令将触发物理零覆写擦除（Zeroize），绝不在内存中长留。

---

### 2. 站点密码派生、自动填充与保存

1. 打开任何需要登录的网站（例如 `github.com`）；
2. 点击浏览器右上角密诀图标，密诀会自动识别当前域名并提取规范站点标识；
3. 输入您的账号/邮箱（如 `myname@example.com`）；
4. 选择密码强度规格：
   - **16位标准**（包含大写字母、小写字母、数字、特殊符号，适配 99% 的网站）；
   - **字母+数字**（适配禁止特殊符号的网站，如部分政务系统）；
   - **PIN 纯数字**（适配 6 位或 8 位纯数字密码）；
5. 输入您的主口令，核对金丝雀指纹无误后，点击 **「保存账号并填充」**；
6. 网页上的用户名与密码框将被瞬间自动填充，同时该站点的**派生规则（仅存域名和账号，不存密码）**将保存在本地清单中。

---

### 3. 站点自定义别名与多域名关联

很多时候，一个账号会对应多个域名，或者域名本身很长不好记（例如 `dash.cdn-fly.xyz`）：
1. 点击面板顶部的 **「📋 记录清单」**，查看所有已存的站点；
2. **设置易记别名**：点击站点名称右侧的 ✏️（小铅笔）图标，即可随时重命名（例如改成 `三毛机场`、`公司内网堡垒机`）；
3. **关联多个镜像/备用域名**：当您访问该服务的新镜像域名时，打开记录清单，点击该条目的 **「🔗 关联当前网页」**，该域名就会自动并入该账号的关联池，下次访问该备用镜像时直接自动匹配！

---

### 4. 密码轮换机制：版本号 (Version) 旋钮

“既然相同的输入算出来的密码永远一模一样，那遇到网站强制要求‘每90天必须修改一次密码’时怎么办？”

**千万不要修改主口令！** 密诀通过 **「版本号 (Version)」** 提供了最优雅的单站点密码轮换方案：
1. 在修改密码页面，将该站点的版本号从 `v1` 调整为 `v2`（点击 `+` 号）；
2. 算法现场基于输入参数 `Version = 2`，立即现场算出一个全新的、在密码学上与旧密码完全统计独立的强密码；
3. 下次需要登录时，密诀记住了当前是 `v2`，依然会精确算出这个新密码；
4. 既实现了单站点的独立轮换，又完全不波及其他站点的密码。

## 三、WebDAV 多端零知识云同步

密诀的云同步**绝不上报任何中心化商业服务器**，只支持标准的 **去中心化 WebDAV 协议**。您可以将其免费挂载在**坚果云、Nextcloud、群晖/威联通 NAS、自建 WebDAV 容器**上。

### 1. 云端同步配置方法（以坚果云为例）

1. 注册并登录坚果云，在「账户信息」->「安全选项」中找到“第三方应用管理”；
2. 添加一个应用密码，名称填 `MantraKey`，生成专用的应用授权密码；
3. 打开密诀扩展或移动端 App，点击右上角 **「🌐 同步」** 按钮；
4. 切换到「WebDAV 云端同步」选项卡，填入配置：
   - **WebDAV 服务器地址**：`https://dav.jianguoyun.com/dav/`（或在后面加上您的专用目录如 `https://dav.jianguoyun.com/dav/mantra-key`）；
   - **用户名**：您的坚果云账号邮箱；
   - **应用密码**：刚刚在坚果云生成的第三方应用授权密码；
   - **远程文件名**：默认 `mantra_sync.mkey` 即可；
5. 点击 **「⚡ 测试连接」**，提示成功后点击 **「💾 保存配置」**。

---

### 2. 独立端到端同步加密密码

在 WebDAV 配置面板中，密诀支持**端到端零知识加密（E2EE）**：
- **默认方式**：直接使用您当前输入的记忆口令派生 AES-256-GCM 密钥加密；
- **独立同步密码（可选）**：如果您希望多个客户端之间共享云端清单，但不想在每个客户端都输入相同的主口令，可以在「同步加密密码」一栏填写一个专属密码；
- 本地在上传前，会使用 `PBKDF2-HMAC-SHA256 (100,000次迭代)` 结合盐值计算密钥，将站点清单打包为二进制密文信封 (`.mkey`)，云端服务商（包括坚果云）只能看到完全无从破解的随机字节乱码。

---

### 3. CvRDT 状态型无冲突自动合并

很多密码管理器在多端同时修改时容易出现“版本冲突”、“覆盖丢失”。
密诀底层实现了 **状态型无冲突复制数据类型 (CvRDT)**：
- 每一个站点的修改都包含毫秒级的逻辑时间戳与版本单调递增判决；
- 无论您在手机上新增了账号，还是在电脑上修改了规则，点击 **「🔄 立即双向同步」** 时，两端数据会自动进行数学级双向无损合并，绝不覆盖任何一侧的新增记录！

## 四、常见问题与故障排查 (FAQ)

### Q1: `启用自动更新.bat` 一定要手动执行吗？不执行会有什么影响？
- **为什么需要执行**：Chrome 浏览器的安全沙箱机制严格禁止任何扩展直接执行本地程序或修改系统注册表。为了实现“在浏览器里点击一键更新，本地代理自动原地下载覆盖”的无感热重载，必须由操作系统侧（用户主动双击 `.bat`）向 Windows 当前用户注册表登记一次白名单。
- **不执行会有什么影响**：**完全不影响日常密码生成、保存与同步等任何核心功能**！唯一的区别是：当有新版本时，点击「⚡ 一键更新」，插件会检测到未注册 Native 代理，平滑降级为直接在浏览器中下载最新的 ZIP 包供您手动替换。

### Q2: 为什么解压目录移动后，自动更新失效了？
- 因为注册表中登记的原生代理路径是指向当时运行 `.bat` 所在的目录。如果您把解压文件夹搬迁到了新的磁盘路径（例如从 `C:\Tools` 移动到 `D:\Tools`），只需在新文件夹中**再次双击运行一次 `启用自动更新.bat`** 即可瞬间重新定位。

### Q3: 忘记了主口令，能够找回吗？
- **绝对无法找回！** 密诀是真正的“零知识、无状态”架构，世界上任何服务器、任何磁盘都没有存储您的主口令，也不存在任何后门或重置机制。请务必将主口令牢记在大脑中，或者以安全的方式（如纸质物理备份）妥善留存。

### Q4: 换了新电脑或手机丢了，我的密码会丢吗？
- **完全不会丢失！** 只要您记得主口令，在新电脑上输入相同的站点域名、账号与主口令，算法现场计算出的密码与旧设备上**百分之百一模一样**；若配合 WebDAV 云同步，在新设备上配好 WebDAV 即可一键拉取全部站点清单。

### Q5: 坚果云等 WebDAV 同步提示 404 或 401 怎么办？
- **401 未授权**：说明用户名或应用密码填错了，注意必须使用坚果云后台生成的“第三方应用密码”，而不是网页登录密码；
- **404 未找到**：如果您填写的服务器地址包含子目录（如 `/dav/mantra-key`），请先登录坚果云网页版，在根目录下手动新建该名为 `mantra-key` 的文件夹，或者直接使用根目录 `https://dav.jianguoyun.com/dav/` 即可。
